Aim for this project
Add a negamax search algorithm for Santorini with
- alpha-beta pruning
- move exploration ordering
- bitboards
Then create a genetic algorithm for the evaluation function of this search tree, find the important coefficients.

what makes a good evaluation function?
- worker mobility
- workers heights
- worker coverage (buildability)
- double each of these by 2 for the opponents 

- closeness of workers to the middle
- distance between workers

Additionally, mobility and coverage can be slightly better if the spots around it are higher for you and lower for opponent (especially 3 build spots where opponent does not have coverage)

current player will be positive, opposing player will be negative regardless of position.
